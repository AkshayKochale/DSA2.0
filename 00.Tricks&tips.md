# <span style="color:orange"> Java Memory Calculation Cheat Sheet </span>

## 1. Memory Units

| Unit | Conversion |
|---|---|
| 1 Byte | 8 Bits |
| 1 KB | 1024 Bytes |
| 1 MB | 1024 KB |
| 1 GB | 1024 MB |

**Conversions:**
- KB = Bytes / 1024
- MB = Bytes / 1024²
- GB = Bytes / 1024³

## 2. Java Primitive Sizes

| Type | Size |
|---|---:|
| byte | 1 byte |
| boolean | JVM-dependent |
| short | 2 bytes |
| char | 2 bytes |
| int | 4 bytes |
| float | 4 bytes |
| long | 8 bytes |
| double | 8 bytes |

## 3. Array Memory Calculation

**Formula:** Memory = Elements × Size of each element

Example:
    int[] arr = new int[10000];

- Elements = 10,000
- Each int = 4 bytes
- Total = 10,000 × 4 = 40,000 bytes
- KB = 40,000 / 1024 = **39.06 KB**

## 4. 2D Array Calculation

    int[][] matrix = new int[1000][1000];

- Elements = 1000 × 1000 = 10⁶
- Memory = 10⁶ × 4 = 4,000,000 bytes
- Total ≈ **3.81 MB**

Note: Java 2D arrays have additional row-array and reference overhead.

## 5. Quick Reference (int[])

| Elements | Memory |
|---:|---:|
| 1,000 | 3.91 KB |
| 10,000 | 39.06 KB |
| 100,000 | 390.63 KB |
| 1 Million | 3.81 MB |
| 10 Million | 38.15 MB |

## 6. Important

- `int[]` stores primitive values directly.
- `Integer[]` stores object references.
- Objects, references and arrays have additional JVM overhead.
- `O(n)` describes memory growth, not exact memory consumption.
- Auxiliary space = Extra memory used by the algorithm.

**Remember:** Identify data type → Count elements → Multiply → Convert into KB/MB.

##  <span style="color:orange"> Character Validation (ASCII) </span>

| Character Type | Valid Range | ASCII Range |
|---|---|---|
| Lowercase letters | a-z | 97-122 |
| Uppercase letters | A-Z | 65-90 |
| Digits | 0-9 | 48-57 |
| Alphabets | a-z, A-Z | 65-90, 97-122 |
| Alphanumeric | a-z, A-Z, 0-9 | 48-57, 65-90, 97-122 |

### ASCII to Array Index

- Lowercase: `c - 'a'` → 0-25
- Uppercase: `c - 'A'` → 0-25
- Digits: `c - '0'` → 0-9

**Remember:** ASCII values of lowercase letters, uppercase letters, and digits are contiguous, making range checks and array indexing efficient.

## Java Character Validation Methods

| Check | Java Method | Meaning |
|---|---|---|
| Alphabet | `Character.isLetter(c)` | Checks if character is a letter |
| Digit | `Character.isDigit(c)` | Checks if character is a digit |
| Letter or Digit | `Character.isLetterOrDigit(c)` | Checks alphanumeric |
| Whitespace | `Character.isWhitespace(c)` | Checks spaces, tabs, etc. |
| Uppercase | `Character.isUpperCase(c)` | Checks uppercase |
| Lowercase | `Character.isLowerCase(c)` | Checks lowercase |
| Valid ASCII | `c >= 0 && c <= 127` | Checks standard ASCII range |

### Important Distinction

- `Character.isLetter()` supports Unicode letters, not just A-Z.
- `Character.isDigit()` supports Unicode digits, not just 0-9.
- For strict ASCII validation, use explicit character range checks.

### Remember
- ASCII validation → Character range checks.
- Unicode validation → Character class methods.
- Java `char` represents a UTF-16 code unit, not necessarily a complete Unicode character.

## <span style="color:orange"> Positive and Negative Number Conversion (Java) </span>

### 1. Positive to Negative
- Multiply by `-1`.
- Example: `5 → -5`

### 2. Negative to Positive
- Multiply by `-1`.
- Example: `-5 → 5`

### 3. Absolute Value
- Removes the negative sign.
- Example: `Math.abs(-10) → 10`

### 4. Toggle Sign
- Unary negation (`-n`) reverses the sign.
- Example: `5 → -5 → 5`

### Important Edge Case
- Java `int` range: -2³¹ to 2³¹ - 1
- `Integer.MIN_VALUE` = -2³¹
- Negating `Integer.MIN_VALUE` causes integer overflow and remains negative.

### Remember
- `-n` → Reverse sign.
- `Math.abs(n)` → Get absolute value.
- Watch out for integer overflow at minimum values.
